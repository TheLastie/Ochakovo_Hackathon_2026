# Каркас карьерного сайта «Очаково» — чекпоинт 1

Первый чекпоинт — почти не оформленный каркас страницы: знакомство с компанией, список профессий, анкета и короткий FAQ. Снимок более оформленной версии сохранён в [`checkpoints/checkpoint-2/site/`](../checkpoints/checkpoint-2/site/).

## Запуск

Из корня этой папки:

```sh
./scripts/dev.sh
```

Для Conda сначала активируйте окружение:

```sh
source ~/miniconda3/bin/activate mush
```

Сайт откроется на http://127.0.0.1:8000. Скрипт предпочитает Python 3.13 и при его отсутствии использует `python3` из активного окружения.

## Файлы

- `web/templates/index.html` — структура страницы.
- `web/src/main.css` — минимальные стили каркаса.
- `web/src/main.ts` — выбор направления и отправка анкеты.
- `web/content.json` — примеры профессий.
- `backend/` — Django-сервер и локальное сохранение анкет.

Форма сохраняет анкеты в локальную базу SQLite. Передача во внешнюю HR-систему не подключена.
