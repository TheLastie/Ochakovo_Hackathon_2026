# Эталонная дизайн-система

 · Принятая основа — оформление документа с брендбуком. [Брендбук](brandbook.md) обязателен вместе с этим файлом. [Визуальный эталон](index.html).

## Цветовые токены

| Токен | Значение | Применение |
|---|---|---|
| `--brand-red` | `#D50032` | Главное действие, смысловой акцент |
| `--surface` | `#FFFFFF` | Основной фон |
| `--ink` | `#151515` | Заголовки и основной текст |
| `--surface-soft` | `#F6F5F2` | Подложки, группировка |
| `--muted` | `#62625F` | Вторичный текст |
| `--line` | `#DCDCD7` | Тонкие разделители |
| `--focus` | `#032AB2` | Клавиатурный фокус, ограниченный служебный акцент |

Красный и белый определяют идентичность; синий не превращается в альтернативную палитру. Естественные цвета кожи, волос, материалов и янтарный цвет Кваска допустимы внутри иллюстрации. В интерфейсе новые цвета не вводятся без смысловой причины и проверки контраста.

## Типографика

- H1: Stratos ExtraBold, `clamp(48px, 6.8vw, 108px)`, межстрочный интервал 1.02, плотность букв около −0.035em.
- H2: Stratos ExtraBold, 36–64 px, интервал 1.05.
- H3: Stratos ExtraBold или Proxima Nova Bold, 24–36 px в зависимости от роли.
- Основной текст: Proxima Nova Regular, 18–20 px, интервал 1.45–1.55.
- Лид: Proxima Nova, 23–28 px. Подписи: 14–16 px; служебные метки 12–13 px не содержат критических инструкций.
- В длинных документах подзаголовки допускают Proxima Nova Bold для спокойного чтения. Пиксельный шрифт не используется для анкет и описания профессий.

## Сетка и расстояния

Основной контейнер до 1440 px; desktop-поля 40 px, промежуточные 24 px, мобильные 18 px. Шкала расстояний: 4, 8, 12, 16, 24, 32, 48, 64, 80. Разделы на большом экране 64–80 px по вертикали; на телефоне 40–48 px. Колонки перестраиваются в одну; длинные таблицы прокручиваются внутри своей рамки.

## Компоненты

**Навигация.** Логотип, ясные ссылки, тонкие линии. На узком экране компактное меню либо горизонтальный список с очевидной прокруткой. Закреплённая панель не закрывает заголовок при переходе по якорю.

**Кнопки сайта.** Основная — красная с белым текстом, радиус 4 px, минимум 44 px по высоте. Вторичная — светлая/контурная с тёмным текстом. Ссылка имеет различимый стиль. Фокус — синий контур 3 px с отступом; hover не заменяет клавиатурное состояние.

**Кнопка главного меню Unity.** По уточнению пользователя от 23 октября 2026 — горизонтальный прямоугольник с прямыми углами (радиус 0), ровная заливка #D50032, белая Proxima Nova Bold из настоящего файла шрифта, равномерные поля. Надпись «За работу!» строго в одну строку, без переноса; это уточнение заменяет прежний квадратный вариант. Прямоугольник сохраняет геометрический язык предоставленного брендбука компании (стр. 57–59) к UI игры; отдельное правило UI-кнопок в источнике не найдено.

**Карточка профессии внутри игры.** Белый фон, тонкая граница, изображение с запасом места, имя персонажа вторично к названию профессии. Два ясных действия: «Попробовать день» и «О профессии». Не показывать зарплату или наличие практики без проверенного предложения.

**Игровой раздел.** С 23 октября 2026 выбрана новая Unity WebGL-сцена: варочный зал по фотографии в стиле панорамы современной фабрики. Светлая среда, тёплые мягкие материалы, металл, читаемые объекты и красные детали. Общая система интерфейса сохраняется. В шаблон сайта добавлен WebGL-контейнер с запуском по нажатию.

**Видео.** Постер, кнопка воспроизведения, длительность из реального файла, субтитры и текстовая альтернатива. Видео не блокирует каталог и анкету.

**Анкета.** Видимые подписи, поля с понятным назначением, ошибки рядом с полем, сохранение введённого при сетевой ошибке в открытой странице. Отправка имеет состояния ожидания, успеха и ошибки; повтор не создаёт дубль. Персонаж не перекрывает поля.

**Персонаж-помощник.** Статичный по умолчанию или короткий осмысленный жест. Реплика не появляется поверх формы сама по себе. Можно свернуть; не открывать снова без причины.

## Ресурсы и производство

Токены: [tokens.css](tokens.css). Шрифты и знак: [происхождение](assets/PROVENANCE.md). Новый код импортирует общие токены, а не копирует произвольные значения по страницам. Иллюстрации сверяются с брендбуком; технические требования к игровым ресурсам определяются после выбора нового формата игры.

Перед выпуском проверить контраст, кириллицу, клавиатуру, уменьшенное движение, небольшие телефоны, медленную сеть и доступность сайта при отсутствии видео или игрового модуля. Текущий эталон — визуальный и компонентный контракт, не заявление о готовности всего продукта.

## Будущая игра

Сайт должен оставаться удобным на телефоне, поддерживать клавиатуру и учитывать уменьшение анимации. Конкретные игровые раскладки и состояния будут выбраны при создании новой концепции.

По решению пользователя от 23 октября 2026 Unity-сцена намеренно очищена для самостоятельного наполнения: сейчас в ней только камера и свет. Игровой блок сайта сохраняет панорамное соотношение 16:10 также на телефоне; WebGL-сборка встраивается в него после обновления. Панорама современной фабрики остаётся возможным художественным ориентиром для будущего содержимого сцены, но не описывает текущий экран.

**Стартовое меню игры (утверждено 23 октября 2026).** Макет со столом реализуется отдельным слоем сайта перед Unity. Белая внутренняя рамка на hover и focus-visible без изменения размеров кнопки; неброское движение только растительности, отключаемое при reduced-motion; звук ветра выключен по умолчанию. Подробности — `docs/game/README.md`.
