# Ochakovo_Hackathon_2026

Материалы проекта собраны по направлениям:

- [Цифровой инструмент](<Цифровой инструмент/>): карьерный сайт и доступные игровые материалы.
- [Концепция бренда](<Концепция бренда/>): брендбук и дизайн-система в `Документы/`, новые материалы опроса в `Исследования/`, изображения мерча в `Мерч/`.
- [Видеоролик о компании](<Видеоролик о компании/>): видео и обложка, подключённые к сайту.

В текущем цифровом инструменте есть сайт, игровое меню и заглушка Unity iframe. Полноценная WebGL-сцена Unity пока не включена.

## Запуск

```sh
cd "Цифровой инструмент/site"
./scripts/dev.sh
```

Сайт откроется на http://127.0.0.1:8000. Скрипт предпочитает Python 3.13 и использует Python из активного окружения, если 3.13 не установлен. Подробности — в [инструкции сайта](<Цифровой инструмент/site/README.md>).
