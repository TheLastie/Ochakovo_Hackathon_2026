# Первая смена — «Очаково»

Игровой карьерный сайт для студентов и выпускников 18–26 лет: познакомиться с производством напитков, попробовать рабочую задачу и сделать следующий шаг к практике или вакансии. Проводник — Михалыч, вымышленный наставник проекта.

Хакатонный прототип объединяет **Unity WebGL**, сайт на **Django** и короткие фильмы о четырёх профессиях. Реализован игровой маршрут **химика-лаборанта** с двумя заданиями. Состояние материалов — 25 октября 2026 года.

## Материалы команды

- [Цифровой инструмент](<Цифровой инструмент/site/>): актуальные исходники сайта, Unity-игры, готовая WebGL-сборка, модели и документация.
- [Концепция бренда](<Концепция бренда/>): брендбук, исследования аудитории и изображения мерча.
- [Видеоролик о компании](<Видеоролик о компании/>): основной ролик и обложка.

![Производственная локация Unity](<Цифровой инструмент/site/docs/game/location/unity-panorama.png>)

## Что можно попробовать

1. Открыть игровое окно со столом стажёра и нажать **«За работу!»**.
2. Выбрать профессию и посмотреть её 30-секундный фильм с Михалычем. Ролик можно пропустить.
3. Для химика-лаборанта — дождаться загрузки и исследовать производственную локацию.
4. Найти рабочую карточку **ЛК-024** на игровом компьютере: сопоставить дату смены, исполнителя и пробу среди рабочих документов.
5. Проверить заявку **«Мохито кислит»**: подготовить порцию образца, измерить pH, зарегистрировать отклонение и передать запрос технологу.
6. Посмотреть финальное обращение Михалыча и перейти к анкете или другой профессии.

Для оператора линии розлива, машиниста оборудования и квасовара готовы экраны выбора и фильмы. После них Михалыч предлагает попробовать сценарий химика или оставить анкету. Отдельные игровые задания этих трёх профессий ещё не реализованы. Описания профессий и анкета доступны без прохождения игры.

## Быстрый запуск

Нужны **Python 3.13**, **Node.js 24** и **npm**. Команды ниже рассчитаны на macOS / Linux; в Windows можно использовать WSL для запуска сайта. Для готовой WebGL-сборки Unity Editor не нужен.

```sh
git clone https://github.com/TheLastie/Ochakovo_Hackathon_2026.git
cd "Ochakovo_Hackathon_2026/Цифровой инструмент/site"
./scripts/dev.sh
```

Открыть **http://127.0.0.1:8000/**; игровое окно — **http://127.0.0.1:8000/#shift**.

Скрипт создаёт `.venv`, устанавливает Python- и npm-зависимости, собирает фронтенд, применяет миграции и запускает Django. Быстрый режим использует локальную SQLite. Готовая сборка в `web/public/unity/` включена в репозиторий. Открывать игру нужно через HTTP, не двойным кликом по `index.html`.

Повторный запуск после установки зависимостей:

```sh
npm run build
.venv/bin/python backend/manage.py runserver 127.0.0.1:8000
```

## Управление

| Действие | Компьютер | Сенсорный экран |
|---|---|---|
| Перемещение | Клик по полу, WASD или стрелки | Касание пола / небольшой джойстик |
| Взаимодействие | Клик по подсвеченной станции; E вблизи | Касание станции |
| Приближение / исходный масштаб | Колесо / Space | Элементы управления сцены |
| Пауза / выход из задания | Esc / экранная кнопка | Экранные кнопки |
| Папки игрового компьютера | Двойной клик; Backspace назад | Касание |

Камера фиксирована и не следует за персонажем. Игровое окно сохраняет пропорции 16:10. Меню, выбор и видео учитывают уменьшение движения и останавливают анимацию вне видимой области или в скрытой вкладке.

## Исходники и устройство

| Путь внутри `Цифровой инструмент/site/` | Содержимое |
|---|---|
| `OchakovoFactoryWorld/` | Unity-проект: сцена, C#-логика, материалы, prefab и настройки |
| `OchakovoFactoryWorld/Assets/Scenes/Brewhouse.unity` | Основная сохранённая производственная локация |
| `OchakovoFactoryWorld/Assets/Scripts/` | Перемещение, компьютер, лабораторное задание, HUD и эффекты |
| `OchakovoFactoryWorld/Assets/WebGLTemplates/Factory/` | Обвязка WebGL и события загрузки / завершения |
| `web/src/` | TypeScript/CSS: меню, выбор, фильмы, загрузка квасом, финал |
| `web/templates/`, `web/content.json` | Django-шаблоны и контент сайта |
| `web/public/` | Изображения, видео и текущая WebGL-сборка |
| `backend/` | Django, API анкеты, административный интерфейс и outbox |
| `art/` | Blender-исходники производственных модулей, продукции и персонажей |
| `brand/` | Дизайн-система проекта, шрифты и происхождение ресурсов |
| `docs/game/`, `docs/video/` | Сценарии, промпты, монтаж, кадры, источники и отчёты проверок |
| `scripts/` | Запуск, сборка и проверки |
| `ОЧАКОВО/` | Исходные материалы кейса и компании |

Сайт передаёт выбранную роль в WebGL и получает события прогресса, готовности, ошибки и завершения смены. Unity загружается для химика после окончания или пропуска фильма. При ошибке можно повторить запуск. Экран со стаканом кваса отображает прогресс загрузки.

Технологии: **Unity 6000.3.22f1**, Built-in Render Pipeline, WebGL; **Python 3.13**, **Django 5.2**, Django REST Framework; **TypeScript**, esbuild для production-сборки, Vite для разработки. Основное серверное окружение предусмотрено на PostgreSQL, Gunicorn и Nginx; конфигурация — `compose.yaml` и `infra/`.

## Редактирование и сборка Unity

Установить **Unity 6000.3.22f1** с модулем **WebGL Build Support**, открыть проект `OchakovoFactoryWorld` через Unity Hub и сцену `Assets/Scenes/Brewhouse.unity`.

После правок сохранить сцену и закрыть Unity Editor:

```sh
./scripts/build-factory.sh
```

Результат появится в `OchakovoFactoryWorld/Builds/WebGL/`. Обычная сборка не обновляет файлы сайта. Для намеренного обновления сборки, которую использует сайт:

```sh
./scripts/build-factory.sh --publish
```

По умолчанию скрипт использует путь Unity для macOS. Другой исполняемый файл задаётся переменной `UNITY_EDITOR`:

```sh
UNITY_EDITOR="/path/to/Unity" ./scripts/build-factory.sh
```

**Не запускайте `FactoryLocationBuilder.CreateAndBuild` или `Factory / Location / Create Production Panorama` для обычной сборки:** они пересоздают композицию и могут заменить ручные правки. Для сборки сохранённой сцены используйте скрипт выше.

Имена бинарных файлов содержат хеши. При обновлении переносите `index.html` и все файлы указанной в нём сборки вместе. Новые сборки игнорируются Git по умолчанию; согласованное обновление готовой демоверсии добавляется явно через `git add -f web/public/unity/` после проверки состава файлов.

## Проверки

Из папки сайта:

```sh
npm ci
npm run build
.venv/bin/python backend/manage.py check
.venv/bin/python backend/manage.py test career
```

Браузерные сценарии находятся в `scripts/check-factory-*.mjs`. Текущие сценарии рассчитаны на macOS с Google Chrome и сайт на порту 8000. Для установки их локальной зависимости:

```sh
npm install --prefix tmp/factory-assets/browser --no-save playwright
node scripts/check-factory-ending.mjs
```

Для других систем потребуется изменить путь браузера в сценарии. Подробности и сохранённые результаты — в документации соответствующих эпизодов. Это технические проверки, а не пользовательское исследование.

## Данные, ограничения и права

- Анкета сохраняется локальным Django-сервером. Внешняя доставка в HR не подключена; прохождение игры не отправляет форму автоматически.
- Для локальной админ-панели создайте пользователя: `.venv/bin/python backend/manage.py createsuperuser`. Адрес — `/admin102/`.
- `.env`, локальные базы, пароли, окружения, кэш Unity и временные файлы не входят в репозиторий. `.env.example` содержит шаблон настроек. Для публичного развёртывания нужны собственные секреты и настройки инфраструктуры.
- Локация — художественная интерпретация производства. Объём 30 мл, диапазон pH 3,20–3,60 и результат 2,72 — игровые параметры, а не спецификация напитка или методика компании. pH не заменяет титруемую кислотность и не определяет причину вкуса.
- Игра не оценивает профессиональную пригодность и не принимает решения о найме. Титрование, выпуск партии и другие профессиональные сценарии остаются за пределами прототипа.
- Сторонние модели Kenney и Quaternius используются по CC0; сведения и лицензии сохранены рядом с ассетами. Логотипы, упаковка, шрифты и материалы компании имеют собственные условия использования. Общая открытая лицензия на весь репозиторий не заявлена.
