# Стартовое меню

`desk.png` — утверждённое пользователем 23 октября 2026 изображение стола стажёра, из `docs/game/menu-concepts/desk-background-v4.png`. Фон создан и отредактирован встроенным image_gen; промпты и происхождение упаковки — в `docs/game/menu-concepts/`. Кнопка запуска и управление звуком реализованы отдельно в HTML/CSS. В изображении сохранилась светлая подложка исходного значка звука; поверх неё расположен рабочий выключатель.

Локальный Proxima Nova Bold подключается через `brand/tokens.css`. Изображение упаковки — концептуальная интерпретация официального референса. Условия источников — `brand/assets/PROVENANCE.md`. Звук ветра синтезируется Web Audio, внешние звуковые записи не используются.

`characters/art/*.webp` — оптимизированные копии четырёх PNG из `docs/game/character-select-concepts/art/`; внешность не перерисована. Рабочий экран выбора — `characters/index.html`, по второму макету пользователя. Источники коротких описаний — `docs/game/character-select-concepts/research.md`.
