# Fonts for the in-game Windows-style desktop

- `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`, `NotoSansMono-Regular.ttf`: Noto project, SIL Open Font License; licence retained in `OFL.txt`. Downloaded from the official `notofonts/noto-fonts` repository, `hinted/ttf/NotoSans/` and `hinted/ttf/NotoSansMono/`, 2026-10-24.
- Source: https://github.com/notofonts/noto-fonts . Noto Sans is used as an open, Cyrillic-capable neutral UI font; it is not Segoe UI. The monospaced font is used inside the simulated Notepad.
- Windows 10 layout is the user's explicit visual reference for this in-world screen. The wallpaper, desktop glyphs and UI are original code-native reconstructions (`FactoryDesktopIcon`, `FactoryWindowsDesktop`); they are not an installed copy of Windows and do not access the host OS or its files.
