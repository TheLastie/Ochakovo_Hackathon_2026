# Ресурсы производственной локации

- `Textures/autoshop_01_1k.hdr` — Autoshop 01, Oliksiy Yakovlyev / Poly Haven. Страница: https://polyhaven.com/a/autoshop_01 ; лицензия CC0: https://polyhaven.com/license . Скачан 24.10.2026 через официальный API, MD5 `8450e5fed3067f4f9c05bbc890e3a22e`. Используется для отражений стали; это не фотография «Очаково» и не фон сцены.
- `Textures/LineHMI.png`, `EpoxyFloor.png` — самостоятельная графика проекта. Данные пульта художественные.
- `Fonts/ProximaNova-Regular.ttf`, `Fonts/ProximaNova-Bold.ttf` — подготовленная локальная версия настоящей Proxima Nova из брендовых демонстрационных ресурсов; условия и исходное происхождение: `brand/assets/PROVENANCE.md`. Не выдавать за отдельно приобретённую лицензию.
- Материалы `Scene_*` — производные фактурных материалов `Assets/FactoryKit`, отдельные от библиотеки.
- Геометрия — существующая собственная библиотека `Assets/FactoryKit` и дополнительные самостоятельные 3D-формы `FactoryLocationBuilder`. Авторская композиция следует предоставленной пользователем панораме.

- `Characters/` — базы Quaternius Universal Base Characters Standard и движения Universal Animation Library Standard (CC0) с рабочей одеждой и сборкой проекта в Blender. Исходные лицензии и FBX — `art/characters/vendor/`; описание — `art/characters/README.md`.
- `Textures/LineHMI_Animated.png`, `SteamSoft.png` — самостоятельная служебная графика проекта для индикаторов и мягких частиц.
