# Перенос игровых материалов

Дата: 25 октября 2026. Целевой репозиторий: `TheLastie/Ochakovo_Hackathon_2026`, ветка `main`.

Источник: текущее рабочее дерево проекта `Hackathon_2026_Ochakovo`; исходный HEAD `a64114a033511c5b6fdd09bc1213eedf6e0683d8`. Перенос выполнен отдельным коммитом поверх истории целевого репозитория.

## Состав

- Полные отслеживаемые исходники `OchakovoFactoryWorld/` (Assets с .meta, Packages и ProjectSettings), `art/`, сценарии и документация игры.
- Сайт с меню, выбором профессии, четырьмя фильмами, экраном загрузки, лабораторным сценарием и финальными обращениями.
- Документация продукта, исходные материалы кейса, брендовые ресурсы, Blender-исходники, видео и сведения о происхождении ассетов.
- Текущий `web/public/unity/index.html` и только четыре Build-файла, на которые он ссылается. SHA-256 сверены с хешами в именах. Исторические сборки не перенесены.

Презентационные экспорты, локальные учётные записи, базы заявок, `.env`, Unity Library/Temp/Logs, окружения, `node_modules` и временные модельные кэши исключены.

## Совмещение

Сохранены структура разделов командного репозитория, настройки внешнего каталога основного видео, Docker-контекст, управление администраторами и исправленные названия профессий. Копии контекста AGENTS.md и CLAUDE.md синхронны. README проекта и Unity обновлены по текущему состоянию игры.

В существующем тесте динамического каталога исправлен входной файл: после замены роли на warehouse тест создавал видео lab_assistant и ожидал его для warehouse. Теперь имя тестового видео соответствует выбранной роли; рабочая логика сервера не менялась.
