# Локальная разработка

Актуальная инструкция запуска, управления и сборки — в [README проекта](../README.md). Основной код находится в `Цифровой инструмент/site/` относительно корня репозитория.

```sh
./scripts/dev.sh
```

Открыть http://127.0.0.1:8000/#shift. Готовая сборка Unity включена; редактируемая сцена — `OchakovoFactoryWorld/Assets/Scenes/Brewhouse.unity`. Работает маршрут химика-лаборанта с компьютером и лабораторной проверкой pH. Остальные профессии показывают фильмы и обращение Михалыча.

После правок TypeScript/CSS выполнить `npm run build`. После правок Unity сохранить сцену, закрыть Editor и выполнить `./scripts/build-factory.sh`. Обновление WebGL сайта — явной командой `./scripts/build-factory.sh --publish`.

Основной ролик компании хранится в разделе `Видеоролик о компании/` корня репозитория; Django использует `COMPANY_VIDEO_DIR`. Персональные данные и базы не входят в Git; внешняя HR-интеграция не подключена. Быстрый локальный режим — SQLite, основное окружение — PostgreSQL / Docker Compose. Администратор создаётся командой `python backend/manage.py createsuperuser`; панель `/admin102/` требует активного superuser.
