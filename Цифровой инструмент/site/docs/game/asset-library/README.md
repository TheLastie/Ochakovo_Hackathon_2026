## Фактурные материалы

По дополнительному запросу пользователя от 24 октября поверхности не ограничиваются сплошным цветом. Подготовлены **6 бесшовных PBR-наборов по 512×512**: направленная шлифовка нержавейки, светлая промышленная плитка со швами, мелкая фактура окрашенного покрытия, древесные волокна, крафтовый картон и резина. Для каждого сохранены Albedo, tangent-space Normal, Roughness и MetallicSmoothness: всего 24 PNG. Последняя карта хранит металличность в RGB, гладкость `1 − roughness` в альфе для Unity Standard. Исходники — `art/factory-kit/generate-textures.py`, готовые карты — `Assets/FactoryKit/Textures/Surfaces/`; все созданы локально процедурно и воспроизводятся из фиксированного seed.

Albedo импортируется как sRGB, нормали как NormalMap, packed-карты как linear. У собственных коробчатых и цилиндрических деталей UV соответствуют приблизительно одному повтору на метр. У сферических и мелких сложных деталей используются исходные UV примитивов; фактура служит микрорельефом. Материалы разделяются между prefab. Добавлена студийная cubemap отражений, чтобы нержавейка читалась металлической при просмотре без запечённого освещения. Зеркальные отражения конкретных помещений и освещение уровней нужно настраивать при сборке локаций.

У Kenney сохранён исходный colormap и исходный UV0. Импортёр добавляет второй UV-канал для мелкого detail-normal окрашенной поверхности; это базовая общая фактура, не индивидуальная PBR-переработка каждого объекта готового набора. Карты Roughness сохранены для Blender; Unity использует упакованную MetallicSmoothness. Настоящая упаковочная графика не заменяется шумом или выдуманными надписями.

## Как открыть и собирать

1. Открыть `OchakovoFactoryWorld` в **Unity 6000.3.22f1**, Built-in Render Pipeline.
2. Для просмотра всех собственных моделей открыть `Assets/FactoryKit/Scenes/AssetGallery.unity`. В Hierarchy объекты пронумерованы и подписаны по-русски.
3. Для примера сборки открыть `Assets/FactoryKit/Scenes/AssemblyExample.unity`. Это отдельная тестовая композиция из варочной зоны, розлива, лаборатории и склада; она не воспроизводит план конкретного филиала.
4. Перетаскивать prefab из `Assets/FactoryKit/Prefabs/<категория>/` в свою сцену. Готовые Kenney-prefab лежат в папках `Prefabs` соответствующих наборов.
5. Стены — 4 м шириной, полы — 2×2 и 4×4 м. Основная привязка 0,5 м; для лабораторных предметов 0,05 м. Размеры в каталоге идут как **X / Y / Z Unity**, в метрах. Пивоваренные ёмкости художественно уменьшены под читаемую игровую среду; это не обмеры настоящего оборудования.
6. Трубы и конвейеры стыковать по дочерним `Socket_In`, `Socket_Out`, `Socket_Branch`. У отдельных приборов есть `Interaction_Read`, `Interaction_HMI`, `Interaction_Sample`, `Interaction_Valve`. Это только точки для будущего кода — заданий и обработчиков взаимодействия ещё нет. Имена могут иметь числовой суффикс Blender; искать по префиксу.

Prefab имеют единичный масштаб, отдельный дочерний `Visual` и простые BoxCollider у крупных предметов. Мелкий реквизит, трубы, светильники и разметка не имеют коллизий. Корневой pivot находится на исходной точке модуля: у большинства предметов внизу, у труб в центре входного торца, у платформы и фермы — по их модульной оси. У ёмкостей и насосов выступающие патрубки входят в общий BoxCollider. У лестницы, стеллажа, дверного проёма и платформы collider пока габаритный: перед реализацией прогулки заменить его составными коллизиями, оставив проходы и ступени свободными.

Основная сцена `Assets/Scenes/Brewhouse.unity` **не изменена**. Сцены-каталоги не добавлены в Build Settings; сайт и его WebGL-сборка не обновлялись. В демонстрационных сценах нет персонажа и управления. Подключение ролей, роликов и рабочих заданий — следующий этап.

## Исходники и воспроизводимость

- `art/factory-kit/generate.py` — оригинальная параметрическая геометрия на Python для Blender 5.0; экспорт всех 60 FBX, каталога и презентационной композиции.
- `art/factory-kit/generate-textures.py` — бесшовные PBR-фактуры; запускать перед `generate.py`.
- `art/factory-kit/factory-kit.blend` — редактируемая библиотека, модели разложены по сетке и коллекциям.
- `art/factory-kit/assembly-preview.blend` — собранный пример с камерой и светом для рендера.
- `art/factory-kit/render-thumbnails.py` — реальные рендеры каждой модели для каталога.
- `art/factory-kit/render-materials.py` — шесть крупных рендеров настоящих материалов для сравнения фактуры.
- `Assets/Editor/FactoryAssetLibrary.cs` — настройки импорта, общие Standard-материалы, prefab, примеры и валидация. Меню **Factory → Assets → Rebuild Library** пересоздаёт только библиотеку и примеры; изменения в этих prefab/сценах перезаписываются. Пользовательские варианты лучше сохранять в других папках или как prefab variants. Меню **Validate Library** проверяет существующие ассеты.

Из корня репозитория:

```sh
python3 art/factory-kit/generate-textures.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/factory-kit/generate.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/factory-kit/render-thumbnails.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/factory-kit/render-materials.py
/Applications/Unity/Hub/Editor/6000.3.22f1/Unity.app/Contents/MacOS/Unity -batchmode -projectPath OchakovoFactoryWorld -executeMethod FactoryAssetLibrary.RebuildLibrary -quit -logFile tmp/factory-assets-unity.log
```

Для генератора текстур нужны NumPy и Pillow (`python3 -m pip install numpy pillow`). Blender-скрипты используют встроенный Python Blender. Каталог пересобирается без повторного скачивания Kenney, если его превью уже сохранены в `docs/game/asset-library/kenney-previews/`.

Перед пакетным запуском Unity закрыть этот проект в Editor. После изменения параметров Blender нужны повторный экспорт и пересборка библиотеки. Для синхронизации HTML-каталога после изменения состава запустить `python3 art/factory-kit/build-catalog.py`.

## Права и границы готовности

Kenney скачаны с официальных страниц [Factory Kit](https://kenney.nl/assets/factory-kit) и [City Kit Industrial](https://kenney.nl/assets/city-kit-industrial); исходные License.txt сохранены. Лицензия — CC0-1.0. Адреса архивов, SHA-256 и перечень импортированных файлов — `Assets/ThirdParty/Kenney/provenance.json`. Платные ассеты, аккаунты Asset Store и Sketchfab и внешние ИИ для создания геометрии не потребовались. Собственная геометрия создаётся локально в Blender, полностью редактируется.

Подлинный логотип скопирован без перерисовки из `ОЧАКОВО/Бренд бук постранично/Брендбук Очаково/ЛОГО БЕЗ КВАДРАТА/031_OCHAKOVO_logoblock_rus_friz03.png`; принадлежит компании, **не CC0**. `PET_Bottle_Prototype` и `Can_Prototype` сохранены как однотонные заготовки. Новые `Ochakovsky_Kvass_PET_500ml` и `Mojito_Fresh_Can_450ml` используют настоящие фронтальные изображения упаковки с сайта компании; полная оборотная развёртка отсутствует. [Происхождение и границы точности](products/README.md).

Проверено в Unity: компиляция editor-кода, импорт FBX, реальные размеры, наличие мешей, Standard-материалы, текстуры Kenney и политика коллизий. Сохранены две сцены, PNG из камеры Unity и машинный отчёт. Собственные 60 моделей суммарно содержат около 72 тысяч треугольников; это объём всей библиотеки, не обещание стоимости каждого уровня. Не проверены кадровая частота на телефоне, финальная WebGL-сборка и прохождение игроком: их оцениваем после сборки настоящей локации. Для библиотеки пока не нужны HDRP/URP, платные shader-пакеты или runtime-зависимости.

В Chrome проверены все 242 превью, поиск, фильтры и ширина 390 px без горизонтального переполнения или ошибок JavaScript. Результаты — `catalog-validation.json`. Фактуры подключены к восьми общим материалам собственного набора; для всех шести наборов проверены карты нормалей и packed-карты.
