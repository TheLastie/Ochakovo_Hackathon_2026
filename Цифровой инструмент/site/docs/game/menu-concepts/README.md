# Визуальные варианты главного меню

23 октября 2026. Визуальное исследование, без реализации в Unity.

## Уточнение пользователя

«Панорама современной фабрики» задаёт только стиль отрисовки. Переносить её производство, вид сверху, планировку или интерфейс в главное меню не требуется. В меню только «За работу!» и регулировка звука. Формат окна — 16:10. Стиль: мягкая стилизованная объёмная графика, тёплый свет, светлая основа, красные акценты.

## Новые направления

1. **Перед сменой.** Красный планшет, карандаш, блокнот и пропуск на освещённом столе; слева кнопка. Личное начало рабочего дня, без производственной панорамы.
2. **Порог.** Приоткрытая красная дверь в светлом помещении; слева кнопка. Простая метафора первого шага.
3. **Михалыч встречает.** Знакомый наставник справа, свободное светлое поле и кнопка слева. Лицо и одежда взяты из проектного референса; объёмная интерпретация пока не утверждена.

Рекомендация для обсуждения — «Перед сменой»: связь с действием создают предметы, при этом экран остаётся камерным и не раскрывает игровой уровень. «Михалыч встречает» сильнее связывает игру с проводником сайта. Это дизайнерские гипотезы.

Промпты сохранены в `revised-prompts.json`. Использован встроенный image_gen. Сгенерированные экраны — концепты для выбора, не рабочий интерфейс, не официальные материалы компании. При реализации текст кнопки и иконка должны быть отдельными элементами Unity UI.

## Доработка «Перед сменой»

23 октября пользователь положительно оценил вариант со столом и запросил атрибутику компании: фотографию и «Стажёр» на бейдже, «Очаково» и текст на планшете, квас «Очаковский» на столе. В редакции `01-before-shift-branded-v2.png` кружка заменена бутылкой кваса, на листе — план первой смены, на бейдже — вымышленный портрет стажёра. Содержание листа — творческий текст проекта, не официальный документ компании. Название компании набрано обычным текстом; официальный логотип генерацией не создаётся.

Референс бутылки 0,5 л ПЭТ: [официальная страница](https://ochakovo.ru/brand/ochakovskij-5/), [исходный PNG](https://ochakovo.ru/wp-content/uploads/2024/09/ochak_05_p.png). Сохранён в `research/ochakovsky-05-pet.png` для визуального сопоставления 23 октября 2026. Публичный источник не означает свободную лицензию. Упаковка в концепте — сгенерированная интерпретация по этому референсу. Промпт: `branded-edit-prompt.txt`, инструмент: встроенный image_gen.
