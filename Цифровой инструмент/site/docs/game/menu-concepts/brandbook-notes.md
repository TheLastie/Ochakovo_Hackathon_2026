# Брендбук компании и кнопка главного меню

23 октября 2026. Источник — материалы пользователя в `ОЧАКОВО/Бренд бук постранично/`, а не наша проектная дизайн-система. Извлечён текст страниц 49–70 раздела «Брендбук Очаково» (страница 62 отсутствует); страницы отрендерены, ключевые страницы 49, 56–59 визуально просмотрены и сопоставлены с макетом.

## Найденные правила

- [Страница 57](../../../ОЧАКОВО/Бренд%20бук%20постранично/Брендбук%20Очаково/page-57.pdf): равные квадратные модули, возможность объединения соседних модулей, равномерные свободные поля вокруг текста. В отдельных случаях допустимы прямоугольники, близкие к квадрату. Это принцип оформления носителей, не специальный стандарт UI-кнопок.
- [Страница 58](../../../ОЧАКОВО/Бренд%20бук%20постранично/Брендбук%20Очаково/page-58.pdf): основной красный Pantone 199, RGB 213/0/50, Web D50032; белый FFFFFF. Палитра названа корпоративной, отдельные палитры HR/Retail описываются в соответствующих руководствах. Для тёмно-серого в таблице расходятся RGB и Web — это не исправлялось догадкой.
- [Страница 59](../../../ОЧАКОВО/Бренд%20бук%20постранично/Брендбук%20Очаково/page-59.pdf): фирменная гарнитура Proxima Nova; Tahoma — рекомендуемая системная гарнитура для офисных документов. Stratos в этих правилах не указан; он ранее был взят проектом из актуального сайта компании.
- Страница 56: красные заливки разбавляются белыми.
- Страницы 50–55: исходные пиктограммы и паттерн имеют зафиксированные пропорции и правила размещения; не следует произвольно пересобирать их генерацией.
- Страница 61: название ОЧАКОВО в тексте набирается прописными без кавычек, с отдельным исключением для юридического наименования.
- Страница 68: при изображении продукта в среде важны фронтальная сторона и фокус на этикетке. Это правило фотостиля, которое учитываем как ориентир для игрового концепта.

## Применение к нашему экрану

По последнему уточнению пользователя от 23 октября 2026 кнопка — горизонтальный прямоугольник с прямыми углами и надписью «За работу!» строго в одну строку. Цвет #D50032, белая Proxima Nova Bold из `brand/assets/fonts/ProximaNova-Bold.woff2`. Прежний квадратный вариант с переносом отклонён и удалён. Принцип квадратных модулей брендбука не является требованием делать UI-кнопку квадратной.

Чтобы гарантировать настоящее начертание, image_gen использован только для удаления старой кнопки и восстановления стены; текст и новая кнопка отрисованы браузером как HTML/CSS с подключённым WOFF2. Макет: `rectangle-preview.html`; фон: `desk-background-v4.png`; финальный PNG: `01-before-shift-rectangle-v4.png`; промпт правки фона: `rectangle-edit-prompt.txt`. Браузерная проверка подтвердила загрузку шрифта, отсутствие переполнения строки; финальный PNG визуально проверен. Unity и сайт не изменены.
