# Экран выбора персонажа

23 октября 2026. Выбран пользователем второй вариант: список профессий и крупный персонаж. Экран подключён к игровому блоку сайта: «За работу!» → выбор персонажа → «Начать смену» → текущая Unity-сцена. Михалыч остаётся проводником сайта.

[Посмотреть на сайте](http://127.0.0.1:8000/#shift). Исходник работающего экрана — `web/public/game-menu/characters/index.html`; `preview.html` сохраняет макет для сравнения. Можно переключать четыре роли: Химик-лаборант, Оператор линии розлива, Машинист оборудования, Квасовар. Под названием — только краткое описание работы. Зарплата, профиль из диплома и блок условий исключены по уточнению пользователя. [Источники и ограничения](research.md).

## Живой отклик

При выборе персонаж коротко появляется с небольшим движением, затем спокойно покачивается и «дышит». Пауза управляется кнопкой под персонажем; при уменьшении движения анимация отключена. Анимации созданы в CSS поверх PNG, руки и лицо не имеют отдельного рига. На сайте работают «Назад», «Начать смену» и синхронный выключатель звука; в сохранённом макете `preview.html` эти действия демонстрационные.

## Ресурсы и проверка

Персонажи в `art/` созданы встроенным image_gen; исходные промпты — `prompts.json`. Это вымышленные игровые образы, не портреты сотрудников. Одежда и предметы — художественная интерпретация; профессиональную точность перед выпуском сверяет профильный эксперт.

Использованы настоящие Proxima Nova Regular/Bold и подлинный SVG логотипа из `brand/assets/`; происхождение — `brand/assets/PROVENANCE.md`. Визуальные ориентиры: утверждённое главное меню и панорама фабрики (стиль отрисовки).

Проверено в Chrome: переключение всех четырёх ролей, отдельная анимация каждого выбора, reduced-motion, загрузка локальных шрифтов, отсутствие горизонтального переполнения при 1600 px и 390 px. Скриншоты — 1600×1000; мобильный макет прокручивается по вертикали, кнопка находится после описания работы.

Вместо CSS-покачивания подключены четыре коротких видео рабочих действий из Google Flow. Видимая кнопка паузы удалена. Исходники, промпты и подготовка для сайта — [animation/README.md](animation/README.md).
