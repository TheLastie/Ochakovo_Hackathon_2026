# Селфи Михалыча в Корзине

Три необязательные пасхалки внутри игрового компьютера:

- `Не_тот_палец.png`: «Палец получился отлично. Меня тоже чуть-чуть видно».
- `Слишком_близко.png`: «Хотел стать ближе к команде. Немного перестарался».
- `Я_и_фикус.png`: «На этом фото у меня особенно свежие идеи».

В Корзине видны миниатюры. Двойной клик (касание на телефоне) открывает приложение «Фотографии». Работают перелистывание, приближение, поворот и восстановление в «Документы». Просмотр прямо из Корзины — намеренное игровое упрощение для доступности пасхалки. Фотографии не дают зачёт основного задания и не нужны для прохождения.

Файлы находятся в [`Assets/FactoryWorld/Textures/MikhSelfies/`](../../../../OchakovoFactoryWorld/Assets/FactoryWorld/Textures/MikhSelfies/). `finger.png`, `closeup.png`, `plant.png` созданы 25 октября 2026 встроенным инструментом **image_gen**. Персонаж вымышленный; это сгенерированные фотографии, не фотографии реального сотрудника. Источник образа — `web/public/characters/mikh.png`; варианты основаны на первом селфи для сохранения лица. Узнаваемые признаки: седой зачёс, усы, круглые чёрные очки, серая рабочая куртка с красными плечами. Юмор доброжелательный, сцены в офисе во время перерыва.

Точные промпты — [`prompts.json`](prompts.json). Исходные PNG сохранены без перезаписи референса. Unity импортирует их с ограничением 1024 px, без mip-уровней, с компрессией.

Исходники: `FactoryWindowsDesktopPhotos.cs`, файловые записи и миниатюры в `FactoryWindowsDesktopFiles.cs`, ресурсы задаются через `FactoryComputerPuzzle` и `FactoryLocationBuilder.ConfigureComputer`. `scripts/check-factory-selfies.mjs` проверяет три изображения, просмотр, перелистывание, приближение, поворот, восстановление и отсутствие влияния на основную головоломку. Результат — `validation.json`; снимки `recycle-bin.png`, `photo-finger.png`, `photo-closeup.png`, `photo-plant.png` получены из WebGL.
