# Производственная локация и запуск Unity

24 октября 2026 пользователь поручил наполнить `OchakovoFactoryWorld/Assets/Scenes/Brewhouse.unity` новой локацией по «Панораме современной фабрики с интерактивными зонами.png». Прежнее ограничение оставлять сцену пустой отменено. HTML-раскадровка не используется как визуальный эталон.

**Компактная локация опубликована по указанию пользователя.** На сайте используется сцена с камерой 5,35, полностью видимым оборудованием и 20 крупными банками мохито. Обычный `./scripts/build-factory.sh` собирает без публикации; `--publish` используется при согласованном обновлении сайта. Проверка запуска — `location/publication-validation.json`.

## Путь на сайте

**Стол стажёра → «За работу!» → выбор профессии → «Начать смену» → 30-секундный ролик выбранной профессии → производство в Unity.** Ролик можно пропустить. Завершение и пропуск используют один переход. До этого перехода Unity-файлы не запрашиваются. При ошибке видео остаются повторный просмотр, возврат и пропуск; при ошибке Unity доступен повторный запуск с выбора профессии.

Все четыре фильма взяты из готовых финальных экспортов `docs/video/professions/{role}/export/{role}-mikhalych.mp4`, копии — `web/public/videos/professions/`. Короткие действия персонажей в самом выборе сохраняются. Видео использует собственное управление воспроизведением; ветер меню при просмотре выключается. При скрытии вкладки или уходе игрового блока из видимости ролик останавливается. Возобновление — кнопкой самого проигрывателя.

Сайт: **http://127.0.0.1:8000/#shift**. Внешних подписей и кнопок вокруг игрового окна не добавлено. Оно остаётся 16:10 и центрируется: ширина не больше 1200 px, высота ограничена доступным экраном с запасом 144 px. На браузерном окне 1280×800 игровой блок занимает примерно 1050×656 и виден целиком. Ограничение едино для заставки, выбора, ролика и Unity; профессии и анкета доступны без игры.

## Локация

[Кадр из Unity](location/unity-panorama.png) · [Состав и ограничения](location/README.md) · [Проверка геометрии и маршрутов](location/unity-validation.json).

Редактируемая сцена включает варочные ёмкости и трубы слева, лабораторию у окон справа, линию розлива поперёк цеха, компактный склад, операторскую и стол с образцами мохито. Использованы библиотека проекта, настоящая упаковка «Очаковского» и «Мохито», фирменная вывеска, фактурные материалы. Это художественная игровая локация по панораме, не обмерная реконструкция конкретного филиала.

Работает прогулка с персонажем: клик по полу, WASD / стрелки, колесо для приближения, Space для исходного масштаба; Esc и кнопка — пауза. Для touch предусмотрены касание и небольшой джойстик. Маршруты строятся по сохранённому NavMesh вокруг оборудования. Камера приближена (ортографический масштаб 5,35), зафиксирована и не следует за персонажем; колесо меняет масштаб только по явной команде. Удалён прежний экранный эффект затенения, который мог давать нестабильные края. Для химика-лаборанта реализован вводный эпизод с подсвеченным компьютером и поиском папки заданий. После найденной карточки доступна заявка «Мохито кислит»: подготовка порции без разбавления, измерение pH и передача отклонения технологу. Слева сверху — портрет и точки этапов, справа снизу — контекстная помощь Михалыча. Титрование, оценивание кандидата и отправка результата в HR пока не реализованы. На сайте Unity запускается только для химика-лаборанта; остальные роли после ознакомительных фильмов видят обращение Михалыча с предложением попробовать химика или оставить анкету. Химик — модель в халате; остальные роли пока используют общий рабочий костюм. Это две новые скелетные модели с клипами, а не четыре уникальных 3D-героя. Коллеги работают с пробой, пультом и вентилем. Банки мохито движутся, дисплеи обновляются, лампы мигают и над вентиляционными выходами ёмкостей виден мягкий пар. Пауза останавливает всю симуляцию. [Модели, источники и клипы](../../art/characters/README.md).

## Исходники

- `Assets/Scenes/Brewhouse.unity` — сама сохранённая сцена; объекты доступны для ручной правки.
- `Assets/Editor/FactoryLocationBuilder.cs` — воспроизводимая сборка композиции и проверка маршрутов. **Factory / Location / Create Production Panorama** заменяет текущую сцену эталонной композицией; не запускать после ручных правок без намерения пересобрать её.
- `Assets/Scripts/FactoryExplorer.cs`, `FactoryAtmosphere.cs` — прогулка и обработка кадра; `Assets/FactoryWorld/` — материалы, текстуры, шрифт и NavMesh.
- `web/src/game-menu.ts`, `web/templates/index.html`, `web/src/main.css` — переходы меню/ролик/Unity. Шаблон Unity — `Assets/WebGLTemplates/Factory/index.html`, протокол progress/ready/error.
- `web/public/game-menu/characters/` — выбор профессии. Изображения WebP, короткие Flow-видео и восстановление прозрачности сохраняются.

Меню со столом, белой рамкой при фокусе, Proxima Nova Bold и выключенным по умолчанию ветром сохраняется. Листва локально движется WebGL-шейдером; reduced-motion и остановка вне экрана учитываются. Меню и выбор реализованы на сайте, а не в Unity.

## Сборка

Для локальной сборки после ручных правок:

1. Сохранить `Brewhouse.unity` и закрыть Unity Editor.
2. Из корня выполнить `./scripts/build-factory.sh`.
3. Просматривать новую сцену в Unity или локально из `OchakovoFactoryWorld/Builds/WebGL/`. Сайт сохраняет опубликованную сборку до явного обновления.

Скрипт собирает `OchakovoFactoryWorld/Builds/WebGL` без изменения сайта. Копирование в `web/public/unity/` выполняется только с `--publish` после отдельного указания пользователя. Меню **Factory / Build WebGL** собирает без копирования. Сохранение сцены само по себе сайт не обновляет. Сборку открывать по HTTP, не `file://`. После изменений TypeScript/CSS выполнить `npm run build`; запуск Django описан в `docs/DEVELOPMENT.md`.

Сборка композиции с нуля и WebGL одним запуском: Unity batchmode `-executeMethod FactoryLocationBuilder.CreateAndBuild`. Этот метод пересоздаёт сцену; обычный `build-factory.sh` только собирает сохранённую.

### Обновление файлов сборки

`FactoryBuilder.BuildWeb` после успешной сборки вызывает `VersionFiles`: имена loader/framework/wasm/data содержат первые 16 знаков SHA-256 содержимого, ссылки в index.html обновляются вместе с ними. `scripts/build-factory.sh` по умолчанию собирает только Unity. Публикация согласованного набора на сайт — только с явным `--publish` по отдельному указанию пользователя. Каждый запуск и повторная попытка на сайте запрашивают index.html с новым параметром attempt, поэтому старый manifest не берётся из кэша. Это защищает от смешивания разных сборок после публикации. Проверка загрузки, повторного запуска и восстановления после ошибки loader — `location/loading-validation.json`.

**Крупный общий план.** Планировка пересобрана под близкую статичную камеру: два резервуара, два лабораторных стола, короткая линия, полностью видимые паллета и погрузчик. Края пола и стены вынесены за кадр; обрезанных передних цистерн больше нет. На ленте 20 увеличенных банок, лицевая сторона определяется по UV и разворачивается к камере. На окне высотой 656 px каждая банка занимает около 33 px по высоте вместо прежних примерно 12 px; это намеренная игровая условность масштаба продукта. Проверка 17 основных объектов и маршрутов — `location/framing-validation.json`, `location/unity-validation.json`.

## Первый интерактивный эпизод

Выбрать химика-лаборанта → подойти к подсвеченному компьютеру у стола слева внизу → E / клик → «Рабочие папки» → «Лаборатория качества» → «Задания на смену» → дата смены → журнал распределения → «Входящие пробы» → `LK024_MOXITO.txt`. Внутри — монитор с рабочим столом Windows 10, Проводником, «Пуском», Блокнотом и калькулятором. На ПК папки открываются двойным кликом, на touch — касанием. Esc возвращает в цех, Backspace — по папкам. Карточка открывает лабораторный стол справа сверху: подготовку порции мышью. Приборный анализ будет следующим этапом. ## Загрузка после профессионального ролика

После конца или пропуска видео появляется стакан, наполняющийся квасом по прогрессу Unity. Загрузка работает на сайте поверх WebGL-окна; сцена и сборка Unity не изменялись. На готовности — 100%, затем плавное раскрытие производства. Ошибка возвращает выбор с повторной попыткой. [Кадры и проверки](loading/README.md).
