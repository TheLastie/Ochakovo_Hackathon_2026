# Оператор линии розлива

[Готовый ролик, 30 секунд](preview.html) · [MP4](export/bottling-mikhalych.mp4)

Управляй ритмом линии: механизмы, датчики, контроль упаковки и результат твоей смены.

## Сценарий

Тысячи движений. Один ритм. Ты — оператор линии розлива. Пригодятся понимание механизмов, датчиков и правил безопасности. Следишь за линией, работаешь с панелью, проверяешь упаковку. Заметил сбой? Сверяешься с инструкцией, сообщаешь команде. Тонкости осваиваешь рядом с опытными коллегами. Твой результат — готовые напитки, ровным потоком. Хочешь управлять этим ритмом? Узнай о практике.

## Производство

Монтаж из Google Flow с одобренным голосовым референсом Михалыча. Речь не ускорялась. Короткие акценты Stratos ExtraBold / Proxima Nova Bold, смена масштаба и положения текста, склейки по рабочим действиям. Оригинальная негромкая ритмическая подложка создана программно; звук исходников Flow не используется. Полные субтитры не добавлены.

В кадрах результата используется настоящая упаковка «Очаковского»: [источник](../shared/PROVENANCE.md). Официальный пэкшот в финале — исходное изображение без перерисовки. Изображённые работники вымышлены; рабочие ситуации — редакционный концепт, не инструкция. Полезные знания не заявляются официальными требованиями вакансии.

Исходники — `source/`; монтаж и временные интервалы — [export/edit.json](export/edit.json); фактическая проверка файла — [export/qa.json](export/qa.json); сборка — [../assemble_series.py](../assemble_series.py). Пользовательские испытания интереса и влияния на отклики не проводились. Сайт и Unity не менялись.
