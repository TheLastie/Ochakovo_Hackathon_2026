# Продуктовые материалы

Сайт включает знакомство с компанией, сведения о профессиях, видео и анкету. Описания профессий и анкета доступны без игры; анкета сохраняется локальным сервером, внешняя передача HR не подключена. Игровое окно загружает текущую Unity WebGL-сборку.

Основа сайта и сервера: Python/Django/DRF, PostgreSQL, Django Templates, HTML/CSS, TypeScript/Vite, Nginx/Gunicorn и Docker Compose. Игра — Unity WebGL; сцена пока пустая и предназначена для наполнения пользователем. Подробности сборки — [в документации игры](../game/README.md).

Единый визуальный контекст: [брендбук](../../brand/brandbook.md) и [дизайн-система](../../brand/design-system.md). Описания профессий не подтверждают наличие актуальной вакансии или стажировки.
