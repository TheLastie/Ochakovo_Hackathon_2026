# Источники и статус утверждений

Материалы обновлены. Исследование компании от  сохранено в [company-research.md](../company-research.md). Ниже — опоры концепции и повторно проверенные технические источники. Это исследование публичных материалов, не интервью с компанией и не проверка её внутренних систем.

## Бриф

- [Исходный кейс](../case-brief.md): аудитория, сезон, набор и цель инструмента.
- Уточнение пользователя: Python + Unity; сначала архитектура и стратегия; варианты брендбука; полный путь кандидата; после выбора удалить отвергнутые направления.
- Ответ пользователя: объём концепции любой, презентуем идею, а не готовое решение. Состав команды и сроки не ограничивают нынешний поиск.
- Предпочтение компанией текущего дизайна — вводная пользователя, а не результат нашего независимого исследования.

## Технические первоисточники, просмотрены 

- [Django 5.2 release notes](https://docs.djangoproject.com/en/5.2/releases/5.2/) — LTS и совместимость Python.
- [Django Admin](https://docs.djangoproject.com/en/5.2/ref/contrib/admin/) — внутреннее управление контентом/данными.
- [Django REST Framework](https://www.django-rest-framework.org/) — API-слой.
- [PostgreSQL](https://www.postgresql.org/docs/current/intro-whatis.html) — база данных приложения.
- [Vite](https://vite.dev/guide/) — сборка браузерного кода.
- [Unity: browser compatibility](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-browsercompatibility.html) — требования и перечни браузеров, включая мобильные; не гарантия производительности конкретной сборки.
- [Unity: browser scripting](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-interactingwithbrowserscripting.html), [примеры взаимодействия](https://docs.unity3d.com/6000.0/Documentation/Manual/web-interacting-code-example.html) — обмен между JS и C#.
- [Unity: настройка сервера](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-server-configuration-code-samples.html) — опора для проверки раздачи Web-сборок.

Стратегия, дополнительный стек и дизайн-система утверждены пользователем. Модель данных, конкретный API и технические детали остаются проектом реализации; они не являются рекомендациями «Очаково» или разработчиков технологий. Точные патч-версии, плагины и инфраструктура фиксируются при начале реализации.
