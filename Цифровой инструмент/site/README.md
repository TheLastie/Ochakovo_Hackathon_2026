# Первая смена — «Очаково»

Карьерный сайт с игрой о работе на производстве напитков. Пользователь выбирает профессию, смотрит короткий ролик с наставником Михалычем и пробует рабочую задачу.

**Реализован сценарий химика-лаборанта:** прогулка по производственной локации, поиск рабочей карточки на компьютере и лабораторная проверка pH по заявке «Мохито кислит». Для оператора линии розлива, машиниста оборудования и квасовара доступны ознакомительные ролики и переход к анкете или сценарию химика.

## Запуск

Нужны **Python 3.13**, **Node.js 24** и **npm**. Команды для macOS / Linux (для сайта в Windows можно использовать WSL):

```sh
git clone https://github.com/TheLastie/Ochakovo_Hackathon_2026.git
cd "Ochakovo_Hackathon_2026/Цифровой инструмент/site"
./scripts/dev.sh
```

Открыть **http://127.0.0.1:8000/#shift**. Скрипт устанавливает зависимости, собирает фронтенд, применяет миграции и запускает Django с локальной SQLite.

Готовая WebGL-сборка включена: для игры Unity Editor не нужен. Открывать сайт следует через сервер, а не как HTML-файл.

## Игровой маршрут

1. **«За работу!»** → выбрать химика-лаборанта → **«Начать смену»**.
2. Посмотреть или пропустить фильм и дождаться загрузки Unity.
3. Подойти к подсвеченному компьютеру слева внизу и найти рабочую карточку **ЛК-024** по дате смены и исполнителю.
4. Перейти к лабораторному столу, подготовить пробу, измерить pH и зарегистрировать отклонение.
5. После обращения Михалыча перейти к анкете или выбору профессии.

Описания профессий и анкета доступны без прохождения игры. Анкета не отправляется автоматически.

## Управление

| Действие | Управление |
|---|---|
| Перемещение | Клик по полу, WASD / стрелки; на телефоне касание / джойстик |
| Станция | Клик по подсвеченному объекту или E вблизи |
| Масштаб камеры | Колесо; Space возвращает исходный масштаб |
| Пауза / выход из задания | Esc или экранные кнопки |

Камера зафиксирована, окно игры — 16:10. Меню и видео учитывают уменьшение движения и скрытие вкладки.

## Структура игры и сайта

Пути относительно `Цифровой инструмент/site/`:

| Папка | Назначение |
|---|---|
| `OchakovoFactoryWorld/Assets/` | Сцена, C#-логика, модели, материалы, анимации и WebGL-шаблон |
| `OchakovoFactoryWorld/Packages/`, `ProjectSettings/` | Зависимости и настройки Unity-проекта |
| `web/public/unity/` | Готовая WebGL-сборка |
| `web/public/game-menu/`, `web/public/videos/` | Меню, персонажи и игровые фильмы |
| `web/src/` | TypeScript/CSS: выбор, видео, загрузка, связь с Unity и финал |
| `web/templates/`, `web/content.json` | Шаблоны и контент сайта |
| `backend/` | Django, анкета и административная панель |
| `brand/` | Оформление и шрифты сайта |
| `scripts/` | Запуск сайта и сборка Unity |

Сайт использует Django 5.2 и TypeScript; production-фронтенд собирается esbuild. Игра — Unity **6000.3.22f1**, Built-in Render Pipeline, WebGL. Основное серверное окружение предусмотрено на PostgreSQL, Gunicorn и Nginx (`compose.yaml`, `infra/`). Основной ролик компании хранится в отдельном разделе репозитория «Видеоролик о компании».

## Редактирование и сборка

Для фронтенда после изменения TypeScript/CSS:

```sh
npm run build
```

Для игры установить Unity **6000.3.22f1** с **WebGL Build Support**, открыть `OchakovoFactoryWorld` через Unity Hub и сцену `Assets/Scenes/Brewhouse.unity`. После правок сохранить сцену и закрыть Editor.

Из папки сайта:

```sh
./scripts/build-factory.sh
```

Результат — `OchakovoFactoryWorld/Builds/WebGL/`. Для обновления сборки, которую запускает сайт:

```sh
./scripts/build-factory.sh --publish
```

Путь к Unity по умолчанию рассчитан на macOS. Для другого пути:

```sh
UNITY_EDITOR="/path/to/Unity" ./scripts/build-factory.sh
```

Генераторы **Create Production Panorama / CreateAndBuild** пересоздают композицию сцены; для обычной сборки используйте скрипт выше. Обновляйте `index.html` и все указанные в нём Build-файлы вместе. Готовая сборка добавляется в Git явно: `git add -f web/public/unity/`.

## Ограничения и ресурсы

- Игровой сценарий реализован только для химика-лаборанта. Профессиональная оценка кандидата и внешняя HR-интеграция не подключены; анкеты сохраняются локальным сервером.
- Лабораторное задание — игровое упрощение. Объёмы и значения pH не являются методикой или спецификацией компании; измерение не определяет причину вкуса и не разрешает выпуск партии.
- Лицензии моделей Quaternius — `OchakovoFactoryWorld/THIRD_PARTY_NOTICES.txt`, Kenney — рядом с наборами в `Assets/ThirdParty/Kenney/`. Происхождение других ресурсов указано в PROVENANCE-файлах. Общая открытая лицензия на все материалы не заявлена.
- `.env`, пароли, локальные базы, окружения и кэш Unity исключены из Git. Для развёртывания нужны собственные секреты и настройки сервера.
