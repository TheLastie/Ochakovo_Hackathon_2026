# Персонажи производственной локации

24.10.2026. Старые персонажи из примитивов Unity заменяются двумя моделями с настоящим скелетом и запечёнными клипами движения.

## Основа и лицензия

База анатомии, топология, UV, лицо, глаза и причёски — **Quaternius Universal Base Characters, Standard FREE**, CC0. Использованы Superhero Female/Male из бесплатного комплекта, без покупки или зависимости от платной Source-версии.

- Официальная страница: https://quaternius.com/packs/universalbasecharacters.html
- Бесплатная загрузка автора: https://quaternius.itch.io/universal-base-characters
- Движения: **Quaternius Universal Animation Library, Standard FREE**, CC0: https://quaternius.com/packs/universalanimationlibrary.html и https://quaternius.itch.io/universal-animation-library
- Лицензии из полученных архивов: `vendor/Base_CC0.txt`, `vendor/Animation_CC0.txt`.

В `vendor/` сохранены только используемые исходники FBX. Полные скачанные архивы находятся в `tmp/characters/` и не являются зависимостью сборки. Доступ к аккаунту, платные покупки и удалённые API для работы игры не нужны.

## Доработка проекта

В Blender подготовлены рабочая одежда, халат, брюки, обувь, кепка, воротник, карманы и бейдж. Одежда привязана к скелету; движения перенесены из библиотеки с учётом различий исходной позы и длины костей, затем запечены в собственные FBX. Исходные анатомические участки под одеждой скрыты геометрией, изображения не генерировались. Образы художественные, не утверждённая спецодежда компании.

Файлы:

- `prepare.py` — воспроизводимая сборка, перенос движений, экспорт и рендеры.
- `chemist.blend`, `bottling.blend` — редактируемые сцены с упакованными текстурами и пятью клипами.
- `manifest.json` — состав экспортов.
- `OchakovoFactoryWorld/Assets/FactoryWorld/Characters/` — FBX, текстуры, материалы, prefab и Animator Controller.
- `docs/game/location/characters/` — крупные планы моделей и поз.

Клипы: Idle, Walk, InspectSample, OperatePanel, OperateValve. Первые два используются игроком; рабочие циклы назначены коллегам на местах. Названия трёх рабочих состояний описывают их применение в сцене, а не новую профессиональную motion capture: исходники — Idle_Torch_Loop, Interact и Push_Loop библиотеки автора. Движение NPC и работа приборов — фоновая сценическая анимация, не технологическая инструкция.

Химик использует женский образ в халате. Остальные три игровые роли пока используют общий мужской образ в рабочем костюме. Это две модели с разными назначениями, не четыре уникальных персонажа. Игровая роль и её ролик сохраняются.

Повторить из корня:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/characters/prepare.py
```

Для импорта Unity используется `FactoryCharacterAssets.Prepare`; он создаёт Built-in материалы и контроллеры, без URP и сторонних runtime-пакетов. Старые примитивные фигуры в сцене не используются.
